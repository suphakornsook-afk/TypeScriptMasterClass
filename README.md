# TypeScript MasterClass

Repository นี้จัดทำขึ้นเพื่อรวบรวมโค้ด ตัวอย่าง และการฝึกฝนเนื้อหาพื้นฐาน TypeScript 
อ้างอิงเนื้อหาการเรียนรู้จากคอร์ส **TypeScript Crash Course** โดย **The Net Ninja** บน YouTube

### Key Topics Learned
- TypeScript Types & Type Inference
- Arrays, Tuples & Enums
- Interfaces & Type Aliases
- Functions & Signature Types
- Classes & Access Modifiers
- Generics & Modern TS Features
